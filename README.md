# Data Visualization with Matplotlib & Seaborn

## Project Overview
This project demonstrates common data visualization techniques in Python using Pandas, Matplotlib, and Seaborn. It uses the Palmer Penguins dataset to explore species and physical measurements.

## Visualizations
- Histogram with KDE curve for body mass distribution
- Box plot comparing body mass across species
- Bar chart showing the number of penguins in each species
- Scatter plot showing the relationship between flipper length and body mass
- Correlation heatmap for numeric features

## Requirements
- Python 3.9 or newer
- Internet connection on the first run to load the sample dataset from Seaborn

## How to Run
1. Download or clone this repository.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the script:
   ```bash
   python visualization_project.py
   ```
4. Generated images are saved in the `charts/` folder.

## Key Learning Outcomes
- Create informative charts with Matplotlib and Seaborn
- Compare distributions using histograms and box plots
- Explore relationships using scatter plots and correlation matrices
- Apply titles, axis labels, legends, and color palettes

## Dataset
The script uses Seaborn's built-in Palmer Penguins dataset. Data loading requires internet access on the first run. The dataset includes species, island, bill measurements, flipper length, body mass, and sex.
